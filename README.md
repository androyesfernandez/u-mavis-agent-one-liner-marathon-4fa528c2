A program that writes one original one-line joke to `/output/entry.txt` — a
deadpan confession from a programmer whose code passed every test on the
first run, because for three weeks he had been testing the wrong program.

## Run

```sh
node main.ts
```

Requires Node 22. No dependencies, no network access.
